Kumpulan soal ini disusun berdasarkan Standar Kompetensi Kerja Nasional Indonesia (SKKNI) Bidang Pemrograman Web Tingkat Junior, mencakup materi HTML, CSS, JavaScript, PHP, SQL, Debugging, dan Uji Coba Unit.

### 1. Unit Kompetensi: Menggunakan Bahasa Pemrograman Web (HTML & Form)
Tag HTML manakah yang digunakan untuk mengelompokkan beberapa opsi pilihan dalam elemen formulir bertipe dropdown?
* A. `<select>` dan `<option>`
* B. `<input type="dropdown">`
* C. `<list>` dan `<item>`
* D. `<datalist>` saja

**Jawaban Benar:** * A. `<select>` dan `<option>`

### 2. Unit Kompetensi: Menggunakan Bahasa Pemrograman Web (PHP Basic)
Dalam PHP, penulisan variabel yang benar dan mematuhi aturan penamaan (case-sensitive) adalah...
* A. `var namaVariabel;`
* B. `$nama_variabel = "Budi";`
* C. `dim $namaVariabel;`
* D. `$nama-variabel = "Budi";`

**Jawaban Benar:** * B. `$nama_variabel = "Budi";`

### 3. Unit Kompetensi: Menggunakan Bahasa Pemrograman Web (Form Handling)
Ketika mengirimkan data sensitif seperti password pada form login, metode HTTP (method) yang paling aman dan direkomendasikan adalah...
* A. GET, karena data dikirim melalui URL dan mudah dibaca
* B. PUT, karena khusus digunakan untuk autentikasi pengguna
* C. POST, karena data dikirim di dalam request body secara tidak terlihat langsung pada URL
* D. HEAD, karena tidak mengembalikan body response

**Jawaban Benar:** * C. POST

### 4. Unit Kompetensi: Menggunakan Bahasa Pemrograman Web (PHP Array)
Manakah sintaks yang tepat untuk mendefinisikan sebuah associative array di PHP?
* A. `$data = ["nama", "umur", "alamat"];`
* B. `$data = array("nama" => "Andi", "umur" => 25);`
* C. `$data = array("nama" : "Andi", "umur" : 25);`
* D. `$data = {"nama": "Andi", "umur": 25};`

**Jawaban Benar:** * B. `$data = array("nama" => "Andi", "umur" => 25);`

### 5. Unit Kompetensi: Menggunakan SQL (DDL vs DML)
Perintah SQL berikut ini yang dikategorikan ke dalam Data Definition Language (DDL) adalah...
* A. `SELECT`, `INSERT`, `UPDATE`
* B. `CREATE`, `ALTER`, `DROP`
* C. `GRANT`, `REVOKE`
* D. `COMMIT`, `ROLLBACK`

**Jawaban Benar:** * B. `CREATE`, `ALTER`, `DROP`

### 6. Unit Kompetensi: Menggunakan SQL (DML)
Jika Anda ingin mengubah nilai kolom `stok` menjadi `15` pada tabel `barangs` untuk barang dengan `kode` 'BRG001', perintah SQL yang benar adalah...
* A. `CHANGE barangs SET stok = 15 WHERE kode = 'BRG001';`
* B. `UPDATE barangs SET stok = 15 WHERE kode = 'BRG001';`
* C. `UPDATE stok = 15 FROM barangs WHERE kode = 'BRG001';`
* D. `INSERT INTO barangs (stok) VALUES (15) WHERE kode = 'BRG001';`

**Jawaban Benar:** * B. `UPDATE barangs SET stok = 15 WHERE kode = 'BRG001';`

### 7. Unit Kompetensi: Menggunakan SQL (Relational Database)

* A. Primary Key

### 11. Unit Kompetensi: Menggunakan Bahasa Pemrograman Web (JavaScript Variable)
Apa perbedaan utama antara deklarasi variabel menggunakan `let` dengan `const` di JavaScript modern (ES6)?
* A. `let` digunakan untuk variabel global, sedangkan `const` hanya untuk variabel lokal.
* B. Nilai variabel `let` dapat diubah kembali (re-assign), sedangkan nilai variabel `const` bersifat konstan dan tidak dapat diubah kembali setelah dideklarasikan.
* C. `let` memakan memori lebih besar dibandingkan dengan `const`.
* D. `const` tidak memerlukan inisialisasi nilai saat deklarasi awal, sedangkan `let` wajib.

**Jawaban Benar:** * B. Nilai variabel `let` dapat diubah kembali (re-assign), sedangkan nilai variabel `const` bersifat konstan dan tidak dapat diubah kembali setelah dideklarasikan.

### 13. Unit Kompetensi: Melakukan Debugging (HTTP Status Codes)
Ketika Anda membuka browser dan mengakses website, lalu server mengembalikan response berupa HTTP Status Code **404**, hal tersebut menandakan...
